# Banco X · Testes automatizados com Selenium

Nesta atividade, você vai usar **Selenium WebDriver** para interagir com o Banco X no Chrome e **JUnit 5** para verificar o resultado. O Banco X é uma simulação que roda no computador.

## Baixe o projeto da etapa

| Etapa | Download | Atividade |
| --- | --- | --- |
| **1 · Login** | [BancoX-Login-Alunos.zip](downloads/BancoX-Login-Alunos.zip?raw=true) | Use o teste pronto do Arthur como modelo. Complete os dois logins válidos e o caso de senha incorreta com os dados da aula. |
| **2 · Operações** | [BancoX-Operacoes-Alunos.zip](downloads/BancoX-Operacoes-Alunos.zip?raw=true) | Use o saque pronto de R$ 150,00 como modelo. Complete o teste de saque de R$ 80,00. A transferência é um desafio extra. |

Cada ZIP contém um projeto independente. Você pode começar a Parte 2 assim que ela for apresentada. O login e a conferência do saldo inicial de R$ 500,00 já estão no código de preparação dessa etapa.

## Comece por aqui

1. Baixe e extraia o ZIP da etapa.
2. Siga o [Guia do Eclipse](GUIA-ECLIPSE.md) para importar o projeto e rodar o exemplo.
3. Consulte as [Dicas de sintaxe](docs/dicas-de-sintaxe.md) enquanto escreve os testes.
4. Quando terminar, rode a classe e entregue o código que completou e um print da aba **JUnit**. Na Parte 2, o teste de transferência pode continuar ignorado.

A resolução será disponibilizada depois da atividade.
